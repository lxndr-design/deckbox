# Deckbox
Manage your MTG deck!

Currently in a beta stage, please note that this isn't signed, and therefore if you are on a Mac you will have to go the route of allowing this thing to run in your security settings.

Features:
- Search for cards amongst all of documented MTG (Using Scryfall as a database)
- Build decks with an intuitive drag and drop interface. Any kind of decks, with any cards
- Manage your collection, see price changes
- Get ideas from random card and deck feeds
